# LINE検索キーワード早見表

LINEで検索するときは、先頭にコマンドを付けると意図が伝わりやすく、誤判定が減ります。

## 1) 予定を探す（カレンダー）

- 基本形: `予定一覧 <期間や条件>`
- 例:
  - `予定一覧 来月`
  - `予定一覧 今週`
  - `予定一覧 2026年6月`
  - `予定一覧 来月 会議`
  - `予定一覧 新会`

質問文だけでも反応することはありますが、確実に予定検索したい場合は `予定一覧` を先頭に付けてください。

## 2) 会話を探す（トーク履歴）

- 基本形: `会話検索 <キーワード>`
- 例:
  - `会話検索 新会`
  - `会話検索 マンチーニ`
  - `会話検索 次は何時`
  - `会話検索 来月 会議`

会話検索は送信後、期間選択（1:1ヶ月 / 2:3ヶ月 / 3:6ヶ月 / 4:12ヶ月 / 5:全期間）を番号で指定します。

## 3) 迷ったときの使い分け

- 予定の日時を知りたい: `予定一覧`
  - 例: `予定一覧 来月 会議`
- 会話の文面・発言履歴を探したい: `会話検索`
  - 例: `会話検索 新会 次回`

## 4) おすすめ入力テンプレ

- `予定一覧 来月 会議`
- `予定一覧 今週`
- `会話検索 キーワード`

短くても、先頭コマンドがあるだけで精度が上がります。
